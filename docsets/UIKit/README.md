# UIkit

This docset contains the UIkit 3.25.26 documentation from the official
[UIkit documentation][1].

## Latest release

The current docset tracks [UIkit 3.25.26][2], released on October 5, 2026.
The older UIkit 2.21.0 archive remains available as a specific version for
projects that still use UIkit 2.

## Generating the docset

The documentation source is the official UIkit website at
[`getuikit.com/docs`][1]. Generate the Dash docset from the current
documentation pages and update `docset.json` whenever a new UIkit release is
published. The UIkit source and release assets are available in the
[official GitHub repository][3].
