# WebExtensions Docset

WebExtensions documentation set for [Dash](https://kapeli.com/dash), based on [MDN WebExtensions](https://developer.mozilla.org/en-US/docs/Mozilla/Add-ons/WebExtensions).

Maintained by [@private_face](https://github.com/private-face), generated by [webextensions-docset](https://github.com/private-face/webextensions-docset).

## Building

The docset is built from unmodified MDN sources with stock MDN tooling (rari + fred). Prerequisites: Node >= 24.

```bash
git clone git@github.com:private-face/webextensions-docset.git
cd webextensions-docset
npm install    # also clones mdn/content
npm run build
```

The result is `WebExtensions.tgz`. To update the docset to the latest MDN content, run `npm run update`.
