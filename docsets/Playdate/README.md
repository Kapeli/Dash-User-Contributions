# Playdate

A docset for the official [Playdate](https://play.date/) SDK documentation,
bundling the three developer references into one offline searchable docset:

- **Inside Playdate** — the Lua API reference
- **Inside Playdate with C** — the C API reference
- **Designing for Playdate** — the design guide

The docset is generated with
[godbout/dash-docset-builder](https://github.com/godbout/dash-docset-builder)
from a small custom generator, and is rebuilt daily to track the upstream SDK
version. Source and build automation:
<https://github.com/captn3m0/playdate-docset>. The latest version can always
be found at <https://github.com/captn3m0/playdate-docset/releases/latest>

The `version` tracks the upstream Playdate SDK version.
