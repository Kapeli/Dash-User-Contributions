Google Apps Script Docset
=======================

This docset replaces the one previously created by [Alexander Maiburg](http://github.com/almai),
with an updated one, generated by [Shay Elkin](https://shay.elkin.io).

It contains the complete reference for all [Google Apps Script Services](https://developers.google.com/apps-script/reference/).

You can download the docset file and use it immediately in [Kapelis Dash](https://kapeli.com) or
generate it from source, using the script in
[shayelkin/google-apps-script-docset](https://github.com/shayelkin/google-apps-script-docset):

```sh
# This uses uv, but any tool that can run scripts with PEP-723 metadata would do
git clone https://github.com/shayelkin/google-apps-script-docset.git
cd google-apps-script-docset
uv run --script fetch.py && \
    uv run --script build.py && \
    uv run uv run --with pytest --with beautifulsoup4 --with lxml pytest -q test_docset.py && \
    open GoogleAppsScript.docset
```
