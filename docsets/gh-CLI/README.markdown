# gh CLI docset

Build requirements:
* `ruby` to generate HTML
* `dashing` to build docset
* `docker` to create the archive

Build instructions:
```shell
git clone https://github.com/toy/gh-cli-docset-builder.git
cd gh-cli-docset-builder
bundle install
bundle exec rake
```
