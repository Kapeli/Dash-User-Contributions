# Bootstrap Icons

This docset contains the Bootstrap Icons v1.13.2 icon library from the
[official Bootstrap Icons website][1].

## Generating the docset

Download the `bootstrap-icons-1.13.2.zip` release archive from the
[Bootstrap Icons v1.13.2 release][2]. Create a Dash docset containing the SVG
files in the archive, using each icon name as a searchable `Icon` entry in
`Contents/Resources/docSet.dsidx`. The generated archive is
`Bootstrap_Icons.tgz`.

The Bootstrap Icons project is maintained by the
[Bootstrap team][3].

[1]: https://icons.getbootstrap.com/
[2]: https://github.com/twbs/icons/releases/tag/v1.13.2
[3]: https://github.com/twbs/icons
